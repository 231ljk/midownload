为什么选择 Nx

七大核心特性，重新定义编程语言

🌐

全场景覆盖

从微秒级内核驱动到分布式微服务，从智能家居到 AI 大模型，一种语言贯穿全栈。

🔄

双范式统一

面向过程与面向对象无缝切换，函数指针、泛型与 Mixin 桥接两种范式。

🤖

AI 原生

意图驱动编程，intent 关键字用自然语言描述功能，编译器结合 LLM 生成代码。

📚

全语言生态

统一 import 语法直接调用 Python/Java/C++/JS/Go/Rust 生态，零开销跨语言调用。

⚡

零成本抽象

借鉴 Rust 所有权模型与 Go 并发原语，不牺牲性能的前提下提供编译期内存安全。

🎯

极简主义

摒弃繁琐类型声明与样板代码，Hindley-Milner 类型推断，新手几分钟上手。

🔧

底层控制力

继承 C/C++ 指针操作与手动内存管理，支持内联汇编与硬件寄存器访问。

🚀

高性能并发

Actor + CSP 混合并发模型，async/await 语法糖，支持百万级协程并发。

简洁直观的语法，双范式统一，几行代码完成复杂逻辑

hello.nx
// Nx Programming Language - Hello World // 双范式统一：面向过程 + 面向对象 // 面向过程：函数定义（类型自动推断） func greet(name) { print("Hello, " + name + "! Welcome to Nx!") } // 面向对象：类定义 + 接口实现 class Circle : Shape { var radius var color = "red" func init(radius) { this.radius = radius } func area() { return pi * this.radius * this.radius } } // AI 意图驱动编程 // intent "计算斐波那契数列第20项" // 全语言生态：直接 import Python 库 // import numpy as np func main() { greet("Developer") circle = Circle(10) print("Area: " + circle.area()) print("\nNx program ran successfully!") } main()

常见问题

快速找到您需要的答案

当前 v0.1.0 是开发者预览版，适合学习、实验和原型开发。我们计划在 v1.0.0 达到生产就绪状态。核心语法和类型系统已基本稳定，后续版本将保持向后兼容。欢迎在 GitHub 上提交 Issue 和 PR 参与开发。
是的！页面上的所有安装命令都是真实可用的。curl | bash 和 PowerShell 命令会从 GitHub 下载安装脚本并执行，自动检测操作系统和架构，下载 Nx 工具链，配置环境变量，并验证安装。安装脚本是开源的，您可以在 GitHub 仓库中查看完整源码。
Nx 的核心优势是"全场景覆盖"和"全语言生态融合"。不同于 Python（性能弱）、Rust（学习曲线陡）、Go（表达力有限），Nx 试图在简洁性、性能、安全性和表达力之间取得最佳平衡。特别是全语言生态融合特性，让您可以用 Nx 直接调用所有主流语言的库，无需重写现有代码。
Nx 是完全开源的项目（MIT License）。您可以通过以下方式参与：1) 在 GitHub 上提交 Issue 报告 Bug 或提出功能建议；2) 提交 PR 贡献代码；3) 编写文档和教程；4) 分享使用经验和最佳实践。我们欢迎所有水平的开发者参与，特别是编译器、类型系统和标准库方向的贡献者。
AI 意图驱动编程是 Nx 的原生特性，使用 intent 关键字用自然语言描述功能意图，编译器结合内置 LLM 生成实现代码，并提供形式化验证接口。例如：intent "创建一个函数，计算给定列表的平均值和标准差"。该功能将在 v0.2.0 版本中推出，支持本地小模型和云端大模型切换，保障代码隐私。
安装完成后，打开新的终端窗口，输入 nx version 查看版本信息，输入 nx help 查看所有可用命令。快速开始：1) nx new my-project 创建新项目；2) cd my-project 进入项目；3) nx run src/main.nx 运行程序。也可以输入 nx repl 进入交互式解释器直接体验 Nx 语法。
